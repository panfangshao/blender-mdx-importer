Blender WarCraft 3 .mdx importer
Blender WarCraft 3 .mdx 导入器

This is an addon for Blender that allows you to import .mdx models and animations from the game WarCraft 3.
这是一个 Blender 插件，允许你从游戏《魔兽争霸3》导入 .mdx 模型和动画。

The addon will work in Blender 5.2.2 LTS.
该插件可在 Blender 5.2.2 LTS 中运行。

This is a fork of PavelBlends version, that only supported Blender 4.54
这是 Nekuromu/blender-mdx-importer 版本的一个分支，原版本支持 Blender 4.54。
